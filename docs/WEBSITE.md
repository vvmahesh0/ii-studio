# Informational website handoff

`website/index.html` is a prepared local informational page using the existing restrained blue/Avenir visual language. It has no generation endpoint, API key form, quotas, analytics or provider calls. It links to the creator account; the official repository URL must be filled in after publication is approved. The local website can be previewed with `python3 -m http.server 8080` from the release root, then open /website/.

No Vercel configuration or deployment is required by the application. The old hosted demo is unchanged. Replacing it is a separate, explicitly approved action. Authentic historical screenshots are labeled accordingly; they are not proof of current release-candidate browser verification.
