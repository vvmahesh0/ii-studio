# Contributing

II studio is an early local-first project by Mahesh V V. Issues are welcome; contributions are reviewed selectively. There is no response-time or support guarantee.

Before substantial changes, open an issue describing the problem and proposed scope. Preserve streaming, local data, current design, schema validation and cancellation. Add focused tests for changed behavior. Never include real prompts, credentials, customer data or browser storage exports in issues or fixtures.

Run `npm ci`, `npm test`, `npm run lint`, `npm run build` and `npx tsc --noEmit`. Use synthetic test content. Live provider tests consume your provider allowance and are optional; report the exact CLI/model/version and limitations.

Contributions are submitted under Apache-2.0. Confirm you have rights to contribute; retain third-party notices. Do not submit proprietary employer/client work. No CLA or support commitment is implied.
